OnOffMate

자율(유연)근무 출근·퇴근 체크를 깜빡하지 않도록 도와주는 보조 도구예요. 매번 사이트에 들어가 확인하는 대신, 이 화면 하나로 오늘·이번 주 근무를 보고 알림까지 받으세요.

시작하기 일정 등록 홈 화면 근무일정 알림 설정 데이터·개인정보 자주 묻는 질문

시작하기

공유받은 주소로 접속한 뒤, 홈 화면에 추가해두면 다음부터는 일반 앱처럼 아이콘을 눌러 바로 열 수 있어요.

iPhone (Safari)

주소 접속 → 하단 공유 아이콘 → 홈 화면에 추가 선택

Android (Chrome)

주소 접속 → 오른쪽 위 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가 선택

별도 회원가입이나 로그인은 필요 없어요. 일정·기록은 이 기기의 브라우저에만 저장돼요.

Onboarding

일정 등록하기

앱을 처음 열면 근무일정이 완전히 비어 있어요. 입력 탭에서 아래 두 가지 중 하나로 채우는 순간부터 홈 화면과 알림이 작동하기 시작해요.

방법 A · 사진으로 한 번에 불러오기

입력 탭 → 📷 카메라로 촬영 또는 🖼️ 갤러리에서 선택 누르기

회사 유연근무 사이트의 월간 근무일정 화면을 바로 촬영하거나, 미리 캡처·저장해둔 사진을 골라 올려요.

기본 패턴과 다른 날짜만 자동으로 채워짐

사진 속 날짜·출근·퇴근 시각을 읽되, 이미 등록해 둔 기본 근무 패턴과 시간이 똑같은 날은 건너뛰고, 반차·단축근무처럼 실제로 다른 날짜만 예외 일정에 반영해요. 몇 초 정도 걸려요.

구글캘린더 반영 여부 확인

일정이 반영되면 바로 "구글캘린더에도 반영할까요?" 팝업이 떠요 — 이유는 아래 알림 설정에서 설명해요.

사진 인식은 별도 로그인 없이 누구나 바로 사용할 수 있어요. 인식이 잘 안 된다면 더 선명한 사진으로 다시 시도하거나 아래 방법 B로 입력하면 돼요.

방법 B · 직접 입력하기

기본 근무 패턴

요일마다 켜고 끄는 스위치와 출근·퇴근 시각을 정해두면 매주 자동으로 반복 적용돼요. (예: 월~목 08:00~18:00, 금 08:00~12:30)

팁 · 나만의 루틴을 기본 패턴으로 등록해두세요

유연근무제는 대부분 월~금 자신만의 루틴한 출퇴근 시간이 있기 마련이에요. 그 루틴을 기본 근무 패턴에 미리 짜두면, 그날그날 다시 입력할 필요 없이 정말 예외적인 날(반차, 단축근무 등)만 아래 "예외 일정"에 따로 추가하면 돼요 — 한 번만 잘 짜두면 그다음부터는 손댈 일이 거의 없어요.

예외 일정

단축근무, 반차처럼 특정 날짜만 기본 패턴과 다를 때 + 예외 날짜 추가로 그 날만 따로 등록해요.

공휴일은 입력하지 않아도 돼요

신정·설날·추석 같은 공휴일은 자동으로 인식해서 근무일정에 노란색 "휴일" 상태로만 표시돼요. 따로 등록할 필요가 없어요.

각 칸에는 그날의 근무 시간과 출근·퇴근 체크 여부가 점으로 표시돼요. 추석 연휴처럼 회사 규정상 공휴일에도 근무해야 하는 날은 다른 휴일과 같은 노란색으로 표시되고, 그 사유가 칸 아래에 적혀요 — 근무 시간 대신이지만 출근·퇴근 체크는 그대로 필요해요.

알림 설정

설정 탭에서 몇 분 전에 알려줄지 고를 수 있어요. 하지만 알림 방식에 따라 신뢰도가 다르니 아래 내용을 꼭 읽어주세요.

화면을 켜두고 있을 때 — 인앱 팝업

이 화면(탭)을 열어둔 동안에는 설정한 시간에 정확히 팝업이 떠요. "확인했어요"를 눌러야 닫히기 때문에 놓칠 일이 없어요. 설정 탭의 지금 알림 팝업 미리보기로 미리 확인해볼 수 있어요. 이 브라우저에서 알림 권한 요청을 함께 켜두면 탭이 뒤에 있을 때도 브라우저 알림이 같이 떠요.

폰이 잠겨 있거나 앱을 완전히 껐을 때는 다름

브라우저 알림은 어떤 웹앱이든 화면이 꺼지거나 앱이 종료되면 신뢰할 수 없어요 — 이 앱만의 한계가 아니라 브라우저 자체의 제약이에요. 이 경우까지 정확히 울리게 하려면 아래 구글캘린더 등록이 필요해요.

폰 잠금·앱 종료 상태에서도 — 구글캘린더 등록

캘린더 앱에 등록된 일정은 폰이 잠겨 있어도 OS가 직접 알림을 울려주기 때문에 가장 확실해요.

📅 지금 구글캘린더에 반영하기 누르기

설정 탭에 있어요. 사진으로 일정을 불러온 직후에는 자동으로 물어봐요.

등록할 항목을 체크(✓)하기

"출근 알림 · 월화수목금 08:00"처럼 요일별로 묶인 반복 알림과, 반차·특근처럼 날짜별 1회성 알림이 함께 나와요. 기본은 전부 체크되어 있고, 필요 없는 항목만 체크를 풀면 돼요.

선택한 일정 캘린더 파일 다운로드 누르기

체크한 항목 전체가 캘린더 파일(.ics) 하나로 저장돼요. 구글캘린더 웹(PC)의 설정(⚙️) → 가져오기/내보내기 → 가져오기에서 그 파일 하나만 올리면, 체크했던 알림이 한 번에 전부 등록돼요 — 하나씩 저장할 필요가 없어요.

항목 옆 바로 열기를 누르면 그 하나만 구글캘린더에서 즉시 열려서 저장할 수 있어요 — 한두 개만 급하게 등록하고 싶을 때 편해요.

기본 패턴(요일별 반복)과 예외 일정을 함께 체크해서 캘린더 파일 다운로드로 등록하면, 예외로 등록된 날짜는 기본 패턴의 매주 반복에서 자동으로 빠져요 — 그 날은 예외 쪽 시각(또는 휴무면 알림 없음)만 적용돼서, 같은 날 두 번 알림이 뜨는 일은 없어요. 다만 이 자동 제외는 캘린더 파일 다운로드에서만 적용되고, 항목별 바로 열기로 하나씩 등록할 때는 적용되지 않아요.

Data

데이터·개인정보

근무 패턴, 예외 일정, 체크 기록은 모두 이 기기의 브라우저 안에만 저장돼요. 서버로 전송되지 않고, 동료나 회사 누구와도 공유되지 않아요.

동료도 각자 독립적으로 써요

같은 주소로 접속해도 각자의 기기·브라우저에 따로 저장되기 때문에, 내 일정이 동료에게 보이거나 섞이지 않아요.

초기화하려면

설정 탭 맨 아래 모든 데이터 초기화로 처음 상태로 되돌릴 수 있어요. 되돌릴 수 없으니 신중히 눌러주세요.

FAQ

자주 묻는 질문

사진에서 일정을 못 읽어요.

사진이 흐릿하거나 달력 형식이 복잡하면 인식이 안 될 수 있어요. 더 선명한 사진으로 다시 시도하거나, 방법 B(직접 입력)로 등록하면 돼요.

알림이 안 울려요.

설정 탭에서 브라우저 알림 권한이 켜져 있는지 먼저 확인하세요. 다만 화면을 꺼두거나 앱을 완전히 종료한 상태라면 브라우저 알림 자체가 원래 신뢰할 수 없어요 — 구글캘린더 등록을 꼭 해두는 걸 권장해요.

기기를 바꾸면 일정도 그대로 옮겨지나요?

아니요. 일정과 기록은 브라우저에만 저장되기 때문에 새 기기·새 브라우저에서는 다시 등록해야 해요.

동료에게 어떻게 공유하나요?

접속 주소만 전달하면 돼요. 회원가입 없이 각자 열어서 자신의 일정을 등록하면 바로 사용할 수 있어요.
